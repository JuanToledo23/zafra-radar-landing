# Zafra Radar · landing

Static landing page for Zafra Radar in two languages, served at https://hola.zafraradar.earth:
English at `/` and Spanish at `/es/`. Plain HTML, CSS and a little JS; the two pages are generated
from one template by a small Python script (standard library only).

## Files

- `content/site.json`: shared settings: `site_url`, `award_url` (empty: the plaque has no link),
  the WhatsApp number, the YouTube video id and the Umami tag values.
- `content/en.json`, `content/es.json`: all the text of each page, its map URL, share text and
  prefilled WhatsApp message.
- `template/page.html`: the page template. `{{key}}` is replaced by an escaped value from the
  content files, `{{&key}}` by a value the build script prepares (HTML or a computed URL).
- `build.py`: fills the template and writes the pages and the share-image sources.
- `index.html`, `es/index.html`: generated pages. Do not edit them by hand; edit the content or the
  template and rebuild.
- `styles.css`, `main.js`: shared by both pages. `main.js` takes its text from the page itself.
- `assets/`: favicon, fonts (DM Sans Bold, SIL Open Font License), hero video and poster, photos,
  link previews `og-en.png` / `og-es.png`, and share images in `assets/share/`
  (story and square, per language; not linked from the pages).
- `share-src/`: templates and styles for the preview and share images, `map-frame.jpg` (the map
  they use), `build/` (generated by `build.py`) and `render.sh`.
- `CNAME`, `.nojekyll`: GitHub Pages.

## Rebuild

After changing `content/*.json` or `template/page.html`:

```sh
python3 build.py              # writes index.html, es/index.html and share-src/build/*.html
sh share-src/render.sh        # writes assets/og-*.png and assets/share/*.png (Chrome + ffmpeg)
```

Run `render.sh` only when the text in the images (plaque, headline, address) or their design
changes. If `site_url` changes, also update `CNAME`.

## Preview locally

```sh
cd zafra-radar-landing
python3 -m http.server 8080
```

Open http://localhost:8080 (English) and http://localhost:8080/es/ (Spanish).
`http://localhost:8080/?lang=es` redirects to the Spanish page. Analytics only count on
`hola.zafraradar.earth`.

## Publish on GitHub Pages

1. Create a GitHub repository and push this folder to its `main` branch.
2. In the repository: Settings → Pages → Build and deployment → Source: "Deploy from a branch",
   Branch: `main`, folder `/ (root)`. Save.
3. Settings → Pages → Custom domain: `hola.zafraradar.earth` (already in `CNAME`).
4. At the DNS provider of `zafraradar.earth`, add a record:

   | Type  | Name | Value                    |
   |-------|------|--------------------------|
   | CNAME | hola | `<github-user>.github.io` |

5. Wait for the DNS check to pass in Settings → Pages, then tick "Enforce HTTPS".
